Bem-vindo ao repositório do meu portfolio pessoal. Este projeto foi desenvolvido para apresentar minha trajetória profissional, habilidades técnicas e projetos em destaque, com um design moderno e interativo.

## 🚀 Sobre o Projeto

Este portfolio é uma Single Page Application (SPA) estática, construída com foco em performance, acessibilidade e estética visual. Ele utiliza conceitos modernos de CSS como Glassmorphism e animações suaves, além de integrar elementos 3D interativos.

### ✨ Funcionalidades

- **Design Responsivo**: Layout adaptável para desktops, tablets e dispositivos móveis.
- **Interatividade 3D**: Um cubo mágico interativo desenvolvido com **Three.js** que responde ao cursor e toque.
- **Animações**: Efeitos de partículas no background e transições suaves entre seções.
- **Seções Detalhadas**:
  - **Home**: Apresentação impactante com resumo profissional.
  - **Sobre**: Detalhes sobre minha carreira e abordagem profissional.
  - **Experiência**: Linha do tempo com minha trajetória (Setec, Totvs, Softtek).
  - **Habilidades**: Grid visual das tecnologias que domino (.NET, Dynamics 365, Power Platform, etc.).
  - **Projetos**: Destaques de projetos pessoais e profissionais.
  - **Contato**: Links rápidos para LinkedIn, GitHub e E-mail.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica.
- **CSS3**: Estilização avançada com variáveis CSS, Flexbox, Grid e animações.
- **JavaScript (ES6+)**: Lógica de interação, menu mobile e manipulação do DOM.
- **Three.js**: Biblioteca para renderização do elemento 3D (Cubo Mágico).
- **FontAwesome**: Ícones vetoriais.
- **Google Fonts**: Tipografia (Space Grotesk e Manrope).

## 📦 Como Executar

Este é um projeto estático, então não requer instalação de dependências complexas.

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Emerson143/Portfolio.git
   ```

2. **Abra o projeto:**
   - Navegue até a pasta do projeto.
   - Abra o arquivo `index.html` em seu navegador preferido.

   *Dica: Para uma melhor experiência (especialmente para carregar texturas ou módulos JS se houver), recomendo usar uma extensão como "Live Server" no VS Code.*
